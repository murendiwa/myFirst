# Contributing Guidelines

Thank you for your interest in contributing to this project!

## How to Contribute

You can contribute by:

- Reporting bugs or unexpected behaviour.
- Suggesting new features and improvements.
- Improving documentation.
- Submitting code improvements.

## Before Making Changes

1. Check existing issues to avoid duplicating work.
2. Explain the change you want to make before starting a major feature.
3. Keep changes focused and easy to review.

## Development Guidelines

- Follow the existing project structure and coding style.
- Write clear and maintainable code.
- Use meaningful names for files, variables, and functions.
- Test your changes before submitting them.
- Update documentation when necessary.
- Never commit passwords, API keys, or other secrets.

## Submitting Changes

1. Fork the repository.
2. Create a branch for your changes.
3. Make and test your changes.
4. Commit your changes with a descriptive message.
5. Open a pull request explaining what you changed and why.

## Questions

For questions or suggestions, open an issue in the repository.

Thank you for helping improve this project!
