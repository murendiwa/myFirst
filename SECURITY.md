# Security Policy

## Reporting a Vulnerability

Security is important to this project.

If you discover a potential security vulnerability, please report it privately to the project maintainer rather than publishing sensitive technical details in a public issue.

## What to Include

When reporting a vulnerability, please include:

- A description of the potential vulnerability.
- The steps required to reproduce the issue.
- The potential impact.
- Any relevant screenshots or supporting information that can be shared safely.

## Response

The project maintainer will review the report and determine the appropriate next steps.

Please allow reasonable time for investigation and remediation.

## Responsible Disclosure

Please avoid publicly disclosing an unpatched vulnerability before the maintainer has had a reasonable opportunity to investigate and address it.

Thank you for helping keep this project secure.
